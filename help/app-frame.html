App frame

The app frames are intended to share app controls and their behaviour across different app views and app dialogs. There is an app Frame control, which is designed to contain and show the controls placed in an specific app frame.

So you can use Frame controls in app views and app dialogs in order to show the controls of the app frames. Remember that an app can have any number of app views, app dialogs, app controls, and, also, any number of app frames.

App frame properties

All the app frames provides to you the below properties, ready to be used:

  • Name property
  • FrameWidth property
  • FrameHeight property

App frame events

The app frames don't provide events by itself, however, you can use all the events provided by the Frame control used to show the app frame.

App frame properties

App frame Name property

Runtime. String variable. The app frame Name property stores the name of the frame as you set it at designtime. Almost all events in the app provides a "frames" JavaScript variable, which you can use to access to the app frame contained controls.

App frame FrameWidth property

Designtime only. String variable. The app frame FrameWidth property allows you to specify an specific with for the app frame. This width determines the default Frame control width, so the app frames scales (see the app styles help topic) in the same way than the app views.

App frame FrameHeight property

Designtime only. String variable. The app frame FrameHeight property allows you to specify an specific height for the app frame. This height determines the default Frame control height, so the app frames scales (see the app styles help topic) in the same way than the app views.
