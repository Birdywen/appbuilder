IDE Open AI assistant

The DecSoft App Builder IDE Open AI assistant allows you to use the Open AI directly from the IDE, in order to get some code advises, for example. You only need to provide your Open AI API key from the program options and then you can start to use the integrated Open AI assistant.

To open the Open AI assistant just choose the Menu -> Tools -> Open AI assistant.
