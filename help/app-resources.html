App resources

DecSoft App Builder allows to set one or more app resources at designtime. These resources consists in an arbitrary number of JavaScript strings, objects, arrays, JSON, etc. Once we compile the app, the app resources are available to be used by using the app.resource() method.

Add app resources and use it is quite easy thanks to the App resources manager, as you can see in the below animated GIF image.

Translated resources

DecSoft App Builder provides also an easy way to translate your app into various languages, and, in addition to the app interface, it's possible to translate the app resources, so we can use it in the right language too. Please, take a look at the app languages manager help topic for more information and details.

There is a Languages sample app included with the installation of DecSoft App Builder. Take a look to see the app resources in action!
