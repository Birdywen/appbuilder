App search

DecSoft App Builder provides a convenient way to search for some specific text around the app, views, dialogs, frames, native controls and plugin controls events. Additionally, the search is also performed on some app properties and some controls properties. You can search for certain text and show the results in the search result editor. Then you can made the changes that you wanted in the search result editor, and, these changes are automatically saved.
